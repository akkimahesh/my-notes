# Download and Install Packer for Windows

[Packer Download Page](https://developer.hashicorp.com/packer/install)

## Installation Steps

1. **Extract it**: Unzip the downloaded archive.
2. **Add path in System Variables**: Add the folder path to your Windows `Path` environment variable.

### ⚠️ Important Path Note

❌ **Do NOT include the `.exe` at the end:**
`C:\Program Files\packer_1.16.1_windows_amd64\packer.exe`

✅ **DO paste the folder path like this:**
`C:\Program Files\packer_1.16.1_windows_amd64`
